# Browstay Multi-Browser Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generalize Stayfari into Browstay, a curated multi-browser current-Space link proxy for Safari, Orion, and Helium.

**Architecture:** Browser definitions provide stable identity, discovery metadata, and a tested new-window strategy. Shared routing, Core Graphics detection, normal opening, default-handler management, persistence, and diagnostics operate on the selected definition; only forced-window AppleScript varies by strategy.

**Tech Stack:** Swift 6, SwiftPM, SwiftUI, AppKit, CoreGraphics, CoreServices Launch Services, NSAppleScript, UserNotifications, XCTest, ad-hoc macOS signing.
